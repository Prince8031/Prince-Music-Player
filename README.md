# Prince — Music Player (Frontend)

Spotify-inspired responsive music player built with HTML, CSS and vanilla JavaScript.

## Run
1. Extract this ZIP and open the folder in VS Code.
2. Open `index.html` with Live Server (recommended), or in a modern browser.
3. Click **Add music** and select audio files from your device.

## Features
- Real browser playback for locally selected audio files.
- Play/pause, previous/next, seek bar, volume, shuffle and repeat.
- Search uploaded tracks, like songs, create playlists.
- Responsive desktop and mobile interface.

## Scope
This is a complete frontend-only version. Audio files are played locally in your browser; they are not uploaded to a server or shared with other users. Playlists and likes reset on refresh. Cloud streaming, user accounts and shared playlists require a backend/database and properly licensed music catalogue.


## Enhanced features
- Dynamic generated album-art colors for each uploaded track.
- Animated equalizer bars while music is playing.
- Lyrics editor: select a track, press the lyrics button in the player, paste lyrics, and save for the current session.
- Lyrics and uploaded audio remain local to the browser session; this frontend does not fetch lyrics from online services or store them permanently.
